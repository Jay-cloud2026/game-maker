# 학위 보상과 NPC 연락 개선

## 원인 분석

- 기존 `hiringSnapshot()`은 `company.salary`만 저장했습니다. 학위별 연봉 차이가 없는 것은
  **UI 오류가 아니라 계산 로직과 우대 정책의 부재**였습니다.
- 학위는 지원 자격에, 연구·논문은 기존 연구 점수에 반영됐습니다. 학위 자체의 직무 가산은 없었습니다.
- 프로젝트 성과급 2%와 2년차 승진 8%는 이미 있었지만 일반 경력 인상과 이직 협상은 없었습니다.
- NPC는 대화 +12/+6, 관련 행동 +3/+6의 친밀도/신뢰를 쌓았습니다.
  과외·동아리·연구실 해금은 보통 친밀도 40/신뢰 30, 교수 추천은 신뢰 50/연구 4,
  팀 동료는 과거 과제 도움과 5학기·신뢰 30이 필요했습니다.
- 해당 보상과 추천서는 실제 연결돼 있었지만 대부분 로그·세부 메뉴에 머물렀고 인턴 추천은 없었습니다.
  정기 연락은 주로 연애 갈등(학기당 추첨 30%)뿐이었습니다.
- 독립적인 NPC 자율 진로·라이벌 성장 시스템은 없었습니다. 이번에는 **핵심 NPC의 작은 진로 이정표**
  만 추가하며 NPC 경제·채용·능력치 시뮬레이션이나 새 라이벌은 만들지 않습니다.

## 기업별 우대 정책

모든 금액은 연간 **만원**, 아래 학위 우대는 해당 대학원 전공과 직무가 관련될 때만 적용합니다.
재학 중인 학위는 인정하지 않으며, 학위만으로 합격이나 최고 인생 등급을 보장하지 않습니다.

| 기업 | 기본 | 석사 우대 | 박사 우대 | 학위 평가 가산(석사/박사) | 경력 1년당 초봉 인정 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 한빛테크놀로지 | 4200 | 400 | 850 | 3/7 | 180 |
| 미래정밀솔루션 | 3600 | 250 | 500 | 2/4 | 200 |
| 다온웨이브 | 3000 | 0 | 0 | 0/0 | 220 |
| 공감도시공사 | 3500 | 0 | 0 | 0/0 | 100 |
| 늘봄융합연구원 | 4000 | 600 | 1400 | 5/11 | 140 |
| 한울대학교 공동연구센터 | 3200 | 400 | 1100 | 4/10 | 100 |

- 학위 전공은 완료한 대학원 프로그램의 명시적 분야 매핑을 사용합니다.
  기록이 없는 이전 학위는 저장된 전공을 사용합니다. 졸업한 전공 대신 새 관심 분야를 임의 추첨하지 않습니다.
- 관련 석·박사는 기존 논문(최대 5편)과 연구실 경험(최대 6회)의 직무별 인정액도 받습니다.
  학사의 연구 준비는 기존 연구 평가 점수에 계속 반영됩니다.
- 경력 인정은 실제 근무 연수 최대 10년입니다. 전공과 무관한 일괄 학위 보너스는 없습니다.
- 관련 박사 + 연구 8 + 논문 1편은 기존 연구기관 내 전문 연구 직책으로 연결됩니다.
  석사는 기존 늘봄의 최소 학위 조건을 해금합니다.
- 교수는 기존 연구·교육·추천서 요건을 갖춘 후일담 진로를 유지합니다. 별도 정교수 채용 시스템은 아닙니다.
- 이직 시 이전 연봉의 104%를 참고하되 기업별 추가 협상 한도를 적용합니다.
  더 낮은 급여의 기업으로 무조건 이전 연봉을 보장하지 않으며 같은 회사 재입사로 협상을 반복하지 않습니다.

### 입사 이후

- 기존 인센티브·승진은 유지합니다.
- 연간 인상률은 기본 1% + 기업 성장성(0.55~0.95%p) + 실제 업무 성과(최대 1%p).
  연구 활용도가 높은 직장의 실제 연구 기여는 추가 0.4%p입니다.
- 해당 연도에는 시작 연봉과 성과급만 지급하고, 인상분은 **다음 근무 연도**에 지급합니다.
- 급여·생활비·대출 상환·저축을 기존 원장에 한 번만 기록합니다.
  현재 연봉과 실제 현금은 기존 인생 결산에 반영하되, 일반 경력 인상을 승진 횟수로 부풀리지 않습니다.
- 지원 당시 연봉·우대 근거·면접 증빙을 스냅샷으로 고정합니다. 이후 능력이나 학위가 바뀌어도
  접수한 원서를 다시 가격 책정하거나 결과를 재추첨하지 않습니다.

## NPC 연락과 실제 연결

새 메뉴 없이 기존 진행 위쪽에 연락 카드 하나만 표시합니다. 수락/집중하기 두 선택이며
참여가 필요한 보상은 **기존 주요 행동**을 사용합니다.

| 연락 | 주요 조건 | 실제 결과 |
| --- | --- | --- |
| 박서우 스터디 | 재학·친밀 30/신뢰 20·남은 행동 있음 | 이번 학기 실제 공부 후 일반 과목 평점 +0.15, 4.5 상한·재수강 상한 보존 |
| 선배 인턴 추천 | 5학기 이후·입학 후 2년·친밀 30/신뢰 25 | 기존 유급 인턴 버튼에 추천 전형. 준비에 따른 확률과 실제 지원 추첨·급여·경험 |
| 교수 연구 과제 | 연구 2·친밀 15/신뢰 35 | 다음 연구 행동 참여 후 연구 기여와 실제 추천서. 추천서 수/품질을 대학원 원서에 반영 |
| 연구 동료 공동 논문 | 연구 4·친밀 30/신뢰 35 | 기존 연구 행동으로 참여. 심사 통과 시 실제 논문 기록·대학원 논문 수·채용 연구 평가/보상 |
| 선배 채용 정보 | 학부 이후·친밀 30/신뢰 30 | 선배 소속과 연결된 기존 채용 공고, 해당 지원 평가 +3·면접 증빙. 학위 조건 면제 없음 |
| 친구 안부 | 스트레스 55 이상·친밀 30/신뢰 25 | 행복 +8·스트레스 -15 |
| 연인의 약속 | 현재 연애 중 | 행복 +10·스트레스 -10·관계 기록 |

- 추천 인턴은 `0.4 + 준비 경험×0.08 + 추천 0.15`, 최대 92%로 선발합니다.
  추천만 받았다고 합격·급여·경험을 미리 지급하지 않습니다.
- 진로 이정표는 입학 연도를 기준으로 선배의 취업(2년)/이직(6년),
  동기의 취업(4년), 연구 동료의 대학원(4년)/공동 연구원(6년), 후배의 첫 직장(6년)입니다.
  플레이어의 휴학·복무 중에도 달력은 흐르므로 이들의 소식도 이후 진행에 반영됩니다.
- 각 종류의 제안은 캐릭터당 한 번, 연락은 반년당 최대 한 번·동시에 하나입니다.
  거절해도 관계 손실은 없으며 같은 연락을 매 학기 반복하지 않습니다.
- 졸업 후 스터디·학부 인턴 제안은 발생하지 않습니다. 유효 기간이 지난 제안은 만료됩니다.
- 연락 생성·결과 확정은 저장되는 진행 전이에서만 실행합니다. 렌더링은 상태·난수를 바꾸지 않습니다.
- 과거에 실제 쌓은 관계 연도와 연구·참여 기록을 원인으로 보여주고, 실제 변화·다음 행동을 설명합니다.
  과거 기록이 없는 이전 저장에 “몇 년 전 친해졌다”는 내용을 소급 꾸며 넣지 않습니다.

## 저장과 검증

- v13 및 4슬롯 형식을 유지합니다. `social.outreach`, 원서/계약의 `recognition`,
  근무 원장의 `salaryReview` 등은 선택적 확장 필드입니다.
- 기존 계약·확정 원서·완료된 인생 결산은 소급 재계산하지 않습니다.
- 첫 새 저장 전 슬롯 원본을 `:before-rewards-v1`에 별도 보관합니다.
  원본 백업에 실패하면 기존 슬롯을 덮어쓰지 않습니다.
- `tests/test_rewards.py`: 기업별 관련 석·박사 보상, 전공 불일치, 학사 경력 역전,
  실제 급여/자산/인생 결산, 원서 고정, 스터디 GPA, 실제 연구→추천서→원서,
  공동 논문·중복 클릭·재접속, 1학년 관계→3학년 인턴 지원, 선배 이직→채용 정보,
  이전 v13 필드 보존을 검증합니다.
- 기존 장기 진행·4슬롯·40세·다섯 SSS 경로는 전체 테스트로 검증합니다.
- 최종 검증: GitHub Actions의 Ubuntu 24.04 환경에서 **20개 테스트 파일 전부 통과**,
  실패/미실행 없음. 실행 기록: https://github.com/Jay-cloud2026/game-maker/actions/runs/45155085503
- 로컬 신규 보상 테스트도 통과했습니다. 기존 장기 UI 테스트는 macOS 브라우저의 클릭 대기에서
  간헐적으로 멈춰 최종 전체 검증은 독립된 Linux 환경에서 진행했습니다.
