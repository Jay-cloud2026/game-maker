# 17번 — 다중 최고 엔딩·인생 종합 평가

사이트 제목: **이번 학기는 진짜 에이 각이다**

## 결과와 범위

기존 통합 확장 1~16번을 기반으로 인생 평가를 추가했습니다.
캐릭터 스키마는 **v13**, 슬롯 형식은 기존 `life-slots-1`을 그대로 사용합니다.

- 다섯 진로에서 각각 SSS~D 가능.
- 기존 취업/학위/회고록 엔딩에 당시 기준과 등급을 저장.
- 언제든 중간 결산을 확인하고 계속 진행하거나 명시적으로 정상 종료.
- 40세 이정표 알림, 계속/종료 선택, 40세 이후 기존 진행 유지.
- 4슬롯의 이름·나이·학력·직업·연봉·순자산·OVR·등급·업적·엔딩 비교.
- 결산에는 돈·능력·경력·시간·추첨 보상이 없습니다.

## 1. 기존 시스템 분석

- 엔딩/타임라인/스냅샷: `memoir.js`의 기존 기록 재사용.
- OVR/진로 경쟁력: `development.js` 재사용. 캐릭터를 인자로 받을 수 있게 하여
  슬롯 비교 때 전역 플레이어를 바꾸지 않도록 했습니다.
- NPC·건강·행복·가족: 기존 필드 재사용. 의학적 병역판정이나 선천 체력에 평가 페널티를 주지 않습니다.
- 별도의 독립 업적 장부는 없었습니다. 학위·대회·프로젝트·논문·학회·승진·관계·
  교환·복무 기록에서 확인되는 업적만 표시하는 읽기 전용 목록을 만들었습니다.
- 창업은 반년 운영·고객 검증·실패·사업 정리/재취업이 이미 구현돼 있었습니다.
- 승진은 제한된 연봉 인상 이벤트, 교수는 조건부 후일담 엔딩입니다.
  **정식 임원 승진 트리/교수 임용·재직/투자 유치·기업가치 산정은 미구현**이며,
  이번 평가가 그런 직책이나 실적을 새로 부여하지 않습니다.

## 2. 평가 기준

### 등급 (설정 파일에서 조정)

| 등급 | 설명 | 기본 최소 종합점수 |
|---|---|---:|
| SSS | 전설적인 인생 | 86 |
| SS | 시대를 대표하는 성공 | 78 |
| S | 뛰어난 성취 | 70 |
| A | 성공적인 인생 | 58 |
| B | 안정적인 인생 | 45 |
| C | 평범하지만 의미 있는 인생 | 30 |
| D | 어려움 속에서 살아온 인생 | 0 |

**점수만 넘는다고 SSS가 되지 않습니다.** SSS는 커리어85/경제55/건강65/관계55/성장15
이상의 공통 하한과 진로별 실적 요건도 충족해야 합니다.
SS/S에도 커리어·건강·관계 하한이 있습니다.
진행 초기에 쌓이지 않은 기록은 낮게 평가될 수 있으며, 사람의 가치에 대한 평가가 아닙니다.

### 축과 중복 방지

- 커리어: 선택한 진로의 실제 프로젝트/연구/사업/숙련/지속 경력.
- 경제: 현금+보증금+현재 사업 현금−부채와 현재 계약의 생활비 차감 소득.
  **누적 저축은 이미 현금에 포함되므로 더하지 않습니다.**
  사업 가치를 임의 추정하지 않으며, 닫은 사업의 반환 자금도 중복 합산하지 않습니다.
- 건강·행복: 에너지 비율·피로·행복·스트레스·운동 습관.
- 관계: 친밀도/신뢰가 높은 두 NPC와 가족 관계. 연애나 결혼은 필수 아님.
- 성장: 중복 활동 키를 제거한 기록상 실제 훈련 증가량과 성장 채널의 폭.
- OVR은 이미 학점·경험·관계를 포함하므로 **표시에만 재사용하고 종합점수에 재합산하지 않습니다.**
  업적 목록/등급 자체에도 추가 점수나 보상을 주지 않습니다.

### 진로별 가중치

| 진로 | 커리어 | 경제 | 건강 | 관계 | 성장 |
|---|---:|---:|---:|---:|---:|
| 대기업 핵심 인재·기술 전문가 | 55% | 15% | 12% | 10% | 8% |
| 연구자·교수 | 55% | 12% | 12% | 13% | 8% |
| 창업가 | 55% | 15% | 12% | 10% | 8% |
| 균형 잡힌 인생 | 20% | 18% | 27% | 25% | 10% |
| 전문 분야 최고 인재 | 50% | 15% | 15% | 12% | 8% |

- 대기업: 대기업 근무8년·프로젝트6회·누적 성과180 이상이 SSS의 추가 최소 요건.
  높은 실제 프로젝트/근속/승진 점수가 필요하며, 취업 자체는 SSS가 아닙니다.
  SSS 기술 전문가형 평가는 가능하지만 임원 직책을 임의 생성하지 않습니다.
- 연구자: 논문4·연구30·학회2·지속 연구 업무4회·교육2 이상과 연구 학위.
  학위/교수 후일담만으로 SSS를 받지 않습니다. 인용지수나 학문적 명성을 꾸며 넣지 않습니다.
- 창업가: 같은 사업의 고객 검증12회·운영16반기 이상.
  실패한 여러 사업의 고객 수를 단순 합산해 최고 등급을 만들지 않습니다.
- 균형: 직업 유지·경력6년·건강80·관계75·운동10·행복75·깊은 관계2명 이상.
  최고 학위나 최고 연봉을 요구하지 않습니다.
- 전문 인재: 경력8년·실무30·프로젝트6회 이상. 대학원 학위 요구 없음.

위 수치는 최고 등급의 **필요조건**이며 가중 점수/공통 하한까지 충족해야 합니다.
모든 조정값은 `life-assessment-settings.js`에 있습니다.

## 3. 기존 진로 연결

- 취업/학위/회고록 엔딩을 별도로 다시 만들지 않고 기존 `ending` 흐름에 최종 평가를 붙였습니다.
- 기존 연구직의 연간 `업무 연구와 개선`에 논문/학회 심사를 연 1회 연결했습니다.
  연구 활용도가 높은 기관에서만 가능하며, 확률·원추첨·결과를 근무 기록에 저장합니다.
  학위 이후 실제 연구 성과를 계속 쌓을 수 있지만 정식 교수 임용 콘텐츠를 대체하지 않습니다.
- 기존 창업 행동에는 실제 훈련 성장 기록을 연결했습니다. 새 창업/투자 시스템은 만들지 않았습니다.
- 승진은 연봉 변화와 확인된 수락만 이용합니다. 거절한 제안을 승진 실적으로 세지 않습니다.
- 구형 엔딩 후일담을 다시 선택해도 같은 시간 키의 돈·경력을 재지급하지 않도록 방어했습니다.

## 4. 자유 결산·종료

`인생 중간 결산·자유 엔딩` 버튼을 사용합니다. 졸업·취업·학위 취득 시점뿐 아니라
플레이어가 원할 때 열 수 있습니다.

- 중간 결산은 원래 선택 화면을 유지합니다. 계속을 누르거나 닫아도 게임이 끝나지 않습니다.
- 평가할 진로를 고를 수 있고, 다섯 진로의 점수·등급·SSS 보완 조건을 모두 볼 수 있습니다.
- `이 결산으로 인생 마무리`를 누르고 확인한 경우에만 정상 종료합니다.
- 자유 종료 전 선택 화면과 회고록을 보관해 `결산 전 진행으로 계속`도 가능합니다.
- 동일한 상태/진로/평가 규칙의 반복 결산은 같은 기록을 재사용합니다.
- 최종 평가는 당시의 기준·가중치·축 점수·등급·전체 타임라인을 저장합니다.
  설정을 나중에 바꾸거나 엔딩 위에서 생활 메뉴를 열어도 원래 최종 평가를 재채점하지 않습니다.

## 5. 40세 결산

- 시간 전이 후 40세 경계를 통과하면 별도 알림과 고정 이정표 기록을 만듭니다.
- 나이·학력·실제 직업/직책·소속·계약 연봉·순자산·OVR/진로 경쟁력·
  생활 상태·주요 관계·업적·종합 등급·타임라인을 표시합니다.
- 강제 엔딩/보상이 아니며 41세 이후에도 기존 근무/사업/연구를 계속합니다.
- 여러 해를 한 번에 넘거나 구버전에서 이미 40세 이상이면
  **현재 나이의 기록**으로 알립니다. 과거 40세의 성과를 만들어 넣지 않습니다.
- 이미 기록한 이정표는 이후 생활이 달라져도 당시의 결과를 유지합니다.

## 6. 슬롯·저장 호환

- 4슬롯 창 상단 비교표를 추가했습니다. 서로 다른 캐릭터를 인자로 읽으며 전역 플레이어,
  RNG, 다른 슬롯의 점수/성장/돈을 변경하지 않습니다.
- 진행 중 슬롯은 저장 시점의 현재 평가, 종료 슬롯은 저장된 최종 등급을 표시합니다.
  나이/재산/OVR 등 현재 저장 값과 과거 최종 등급은 시점을 명시해 구분합니다.
- v1~v12 단일/슬롯 저장을 v13으로 이전하고 `lifeAssessment`만 추가합니다.
  기존 엔딩 스냅샷·입시·원서·성적·학위·군 복무·가족·장비는 재생성하지 않습니다.
- 슬롯 원본은 `:before-assessment`, 단일 저장은 기존 `:backup-v12` 등의 키로 보존합니다.
- 과거 훈련 증가 이력이 없는 저장에는 가상의 과거 성장/업적을 지급하지 않습니다.

## 7. 수정 파일·검증

- 추가: `life-assessment-settings.js`, `life-assessment.js`, `test_life_assessment.py`.
- 수정: `memoir.js`, `career.js`, `game.js`, `slots.js`, `life.js`, `settings.js`,
  `development.js`, `study.js`, `campus.js`, `military.js`, `index.html`,
  `test_validation.py`, `run_all_tests.py`, `README.md`.
- 사이트 `<title>`, 화면 `<h1>`, README 제목을 요청한 이름으로 변경했습니다.
- 성장 평가가 실제 기록을 사용하도록 복무 학습 배율 적용 후의 증가량도 성장 이력에 맞췄습니다.

**전체 테스트:** `python3 run_all_tests.py` — 17개 테스트 파일.
결과는 `.artifacts/TEST_RESULTS.json`, 다섯 SSS 경로의 점수/축/나이/연봉은
`.artifacts/LIFE_ASSESSMENT_TEST_RESULTS.json`에 남깁니다.

새 테스트에서 다음을 검증합니다.

1. 대기업 프로젝트 누적·승진 후 SSS.
2. 학사 상태로 중견 실무 경력을 쌓아 SSS.
3. 보통 신입 연봉의 직장에서 건강·관계·균형을 유지해 SSS.
4. 석사/박사 후 연구직의 논문·학회·지속 연구를 쌓아 SSS. 박사 단독 SSS는 차단.
5. 기존 창업에서 16반기 실제 운영·고객 검증 후 SSS.
6. 큰 자산/연봉·높은 OVR도 건강·관계·성장 결핍 시 SSS 차단.
7. 39→40→41세 실제 업무 진행, 이정표 1회·당시 결과 보존, 시간 점프/구버전 현재 기록 처리.
8. 중간 결산 반복 시 돈·시간·경험·성장 난수·타임라인 보상 불변.
9. 자유 종료/재개·최종 평가 재접속·기준 변경 시 저장 결과 유지.
10. 서로 다른 네 삶 비교의 순수성·모바일 화면·v12 엔딩 원본 보존.

경력과 사업 운영은 실제 UI로 진행합니다. 건강/NPC는 졸업 전 상태를 명시한
시작 픽스처를 사용하므로, 다섯 삶을 매번 고교 생성부터 전부 완주했다는 뜻은 아닙니다.
분기 재현에는 테스트 전용 고정 난수를 사용했고 실제 게임에는 자동 성공 처리가 없습니다.

## 후속 단계로 남긴 콘텐츠

- 정식 임원 승진/기술 직급 트리, 교수 임용/재직·연구실 리더십 상세 진행.
- 투자 유치·지분·기업가치·주식시장·연구 인용지수.
- 대규모 장기 확률 밸런스 시뮬레이션, Safari/Firefox 전 조합 검증.

현재 평가 화면은 이 미구현 콘텐츠를 완료된 직책/업적처럼 표시하지 않습니다.
최고 등급은 현재 구현된 삶의 기록에 대한 평가이며 임용·승진 보상이나 직업 변경이 아닙니다.
