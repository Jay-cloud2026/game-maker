# 이번 학기는 진짜 에이 각이다

고교 졸업부터 입시·재수·대학 생활·취업·대학원·인생 회고록까지 이어지는
한국어 선택형 인생 시뮬레이션입니다. 학교·기업·연구실은 모두 가상입니다.

**플레이 링크:** https://jay-cloud2026.github.io/game-maker/

**통합 확장:** 기존 1~9단계와 17번 인생 종합 평가를 적용했습니다. 캐릭터 저장 버전은 **v13**,
4슬롯 컨테이너는 `life-slots-1`입니다.
다중 SSS·자유 결산·40세 이정표·슬롯 비교의 기준과 검증은
[`docs/LIFE_ASSESSMENT.md`](docs/LIFE_ASSESSMENT.md)에 있습니다.

## 실행

이 폴더의 파일을 함께 두고 **`index.html`을 브라우저에서 열면** 실행됩니다.
서버·외부 라이브러리·인터넷 연결이 필요하지 않습니다.

GitHub Pages로 배포할 수 있는 정적 웹 게임입니다. 방문자별 진행은 각 브라우저에만 저장되며
계정 로그인이나 서버 저장은 없습니다. 로컬 파일에서 웹 링크로 옮길 때는
기존 게임에서 **전체 슬롯 백업**을 내려받고 웹 게임에서 불러오세요.

- 새 게임: `저장 슬롯 4개`에서 빈 슬롯을 선택하고 캐릭터 생성부터 시작.
- 기존 게임: 같은 브라우저·파일 경로에서 자동으로 이어하기.
- 학부는 학기당 주요 행동 3회. 식사·교류·신청·연구 활동의 횟수와 비용은
  각 선택지에 표시됩니다.
- 학기 초 재정 화면에서 주거·장학금·대출을 정한 뒤 정산합니다.
- 현재 학기 평점은 행동 3회 후 성적표를 열어야 공개됩니다.
- 연구실·어학은 학부/대학원 진행 화면에서, 교환학생은 학부 3~6학기에 지원합니다.
- 휴학은 등록금 정산 전이나 방학 결과 화면에서 신청합니다.
- 졸업 후 채용·국내외 대학원을 선택하고, 직장·창업·연구·교육 경력을 이어갈 수 있습니다.
- 엔딩 화면에서도 실제 경험으로 열린 후일담과 박사 이후 진로를 선택할 수 있습니다.
- 석사는 기본 4학기, 박사는 프로그램별 6~10학기(기본 8학기), 학기당 주요 행동 3회입니다.
  자료·논문·발표·교수 피드백·자격시험·디펜스가 부족하면 추가 학기를 진행합니다.
- `생활·가족·상점`: 운동/수면은 기간당 합계 2회. 가족 지원과 장착 효과를 관리합니다.
- `병역·복무 일정`: 대상 캐릭터는 판정·연기·복무 경로를 확인합니다.
  복무 중에는 3개월마다 자기계발하며 학부 학기는 정지합니다.
- 취업 후 바로 정상 취업 엔딩을 보거나 직장 생활을 계속할 수 있습니다.
- `인생 중간 결산·자유 엔딩`: 다섯 진로의 SSS~D 평가를 확인하고 계속/종료를 선택합니다.
  결산 자체에는 보상이 없으며, 40세가 되거나 그 나이를 넘으면 별도 이정표가 도착합니다.
  이후에도 플레이할 수 있습니다. 슬롯 창에서 네 캐릭터의 삶을 비교할 수 있습니다.

## 저장과 백업

- 선택할 때마다 브라우저 `localStorage`에 저장합니다.
- 기존 v1~v12 저장본을 v13으로 이전해 첫 슬롯에 보관합니다.
  기존 단일 저장 키와 버전별 원본 백업은 지우지 않습니다.
- 기존 입시·성적·자금·관계·진행 단계는 유지합니다.
- v1/v2의 과거·진행 중 학기에 새 비용을 소급 청구하지 않습니다.
- `현재 슬롯 수동 저장`, 캐릭터 JSON 내보내기/불러오기, `전체 슬롯 백업`이 가능합니다.
  전체 슬롯 JSON을 가져올 때는 4개 슬롯 덮어쓰기를 별도로 확인합니다.
- 불러오기 전 현재 자동 저장본도 별도 백업하며, 잘못된 파일은 현재 진행을 바꾸지 않습니다.
- 슬롯 전체는 하나의 레코드로 쓰고 직전 레코드를 먼저 백업합니다.
  저장 실패 시 원본은 유지하고, 손상된 저장은 직전 백업에서 복구합니다.
  다른 창에서 갱신한 슬롯을 오래된 창이 덮어쓰지 않도록 revision 충돌을 차단합니다.
- 브라우저 저장 차단·비공개 모드·파일 경로 변경은 자동 이어하기에 영향을 줄 수 있습니다.
  장기 보관에는 저장 파일 내보내기를 사용하세요.

- `game.js`: 공통 상태 전이·저장·성적표·대학원 진행

## 검증

Python Playwright와 Chromium이 있는 환경에서:

```sh
python3 run_all_tests.py
```

필요한 테스트 도구가 없다면 별도로 설치합니다.

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
```

테스트는 `tests/`, 현재 규칙 문서는 `docs/`에 있습니다.
`.artifacts/TEST_RESULTS.json`에 테스트별 통과·실패·미실행 목록을 남깁니다.
생성된 결과·로컬 캐시·배포 산출물은 Git에 포함하지 않습니다.

## GitHub Pages 배포

`main`에 푸시하면 GitHub Actions가 전체 테스트를 통과한 뒤 자동 배포합니다.
저장소의 Settings → Pages → Source는 **GitHub Actions**로 설정합니다.

```sh
python3 scripts/build_site.py
```

배포 산출물 `_site/`에는 `index.html`과 실제 참조된 게임 스크립트만 포함됩니다.
테스트·문서·개인 저장 파일은 사이트에 배포하지 않습니다.

## 모델의 범위

학점·비용·시간은 플레이하기 쉽도록 압축한 게임 규칙이며 실제 입시·취업 예측 모델이
아닙니다. 학부 기본 8학기, 석사 4학기, 박사 기본 8학기이며 연구 심사에 따라 연장됩니다.
병역의 실제 제도와 게임용 판정·급여·행정 단순화는 [`docs/MILITARY_RULES.md`](docs/MILITARY_RULES.md)를 확인하세요.
대출은 무이자 모델입니다. PC·모바일 Chromium으로 검증하며 다른 브라우저에서의
모든 조합을 보장하는 것은 아닙니다.
